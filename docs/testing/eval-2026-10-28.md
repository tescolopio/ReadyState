## Findings

| # | Finding | Evidence | Action |
| --- | --- | --- | --- |
| 1 | **The provider's daily token limit ends the session, with no explanation.** Groq's free tier allows 200,000 tokens per day per model; this run used it up. The app said only "An error occurred." | Server log: 429 "tokens per day (TPD): Limit 200000" | ✅ Fixed (G4): a specific message with the wait time, and no raw provider text, which carries the account id. |
| 2 | **The model invents resources the household doesn't have.** This undercuts the inventory check. | Alex (no generator, no cat): "the generator sputters", "kitty litter you kept in your bag", "the battery-powered electric blanket you keep". Priya also gets a generator. | ✅ Prompt rule added: resources exist only if listed or obtained in the story. **Not yet re-verified on 120b** (quota). Track under G9. |
| 3 | **The clock moves too slowly.** 2–6 hours per turn, so 72 hours takes about 20 turns. | Priya: 15 turns to Hour 46 | ✅ Prompt now asks for 6–12 hours per turn (about 8–10 turns per exercise). Not yet re-verified. |
| 4 | **Developments repeat.** | Sam: a gas smell three times (own furnace, neighbor's kitchen, neighbor's water heater); CO detector "low battery" twice. | ✅ Prompt rule added: vary developments and don't repeat resolved hazards. Not yet re-verified. |
| 5 | **The safety heuristic flagged warnings as advice.** | Flagged sentences all warned against indoor fuel use ("creates carbon monoxide") | ✅ The runner now treats sentences about the hazard as warnings. One borderline case remains worth a human look: Morgan's feedback objected to a generator in the garage only because of flood risk. That's work for the G11 model judge. |
| 6 | **gpt-oss-20b sometimes returns an incomplete turn,** which Groq rejects. | "parameters for tool generate_turn did not match schema: missing properties 'time_elapsed', 'suggested_actions', 'scenario_status'" | ✅ Clear message ("The model returned an incomplete turn…"). Still to do: retry once automatically (G4), and record 20b as less reliable (G3). |
| 7 | **The eval reported provider errors as "empty response".** | – | ✅ The runner now records the error text. |

**What worked well:** Priya's heat wave was realistic and well paced in content, though not in clock time. The power station drained, heat exhaustion developed, and the cooling center could only take her for 6 hours. Feedback consistently cited what the response actually said.
